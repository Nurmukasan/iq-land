# IQ LAND

Рабочая первая версия сайта международных олимпиад: публичная афиша, регистрация команды учителем и два защищённых кабинета организаторов.

## Быстрый запуск

Нужен Node.js 24 или новее (используется встроенный SQLite). Проверьте версию командой `node --version`.

### Windows / PowerShell

Сначала скопируйте **файлы проекта** на свой компьютер: одного пустого клона GitHub недостаточно. В скачанном архиве исходников есть каталог `iq-land` с `package.json`, `package-lock.json`, `src`, `server` и `public`. Распакуйте его в новую папку, сохранив существующие локальные файлы.

Откройте PowerShell именно в распакованном каталоге `iq-land`, где лежит `package.json`:

```powershell
Get-Item .\package.json, .\package-lock.json
node --version
npm ci
npm run dev
```

Оставьте терминал открытым и откройте в браузере адрес, который напечатает Vite. Параметр `--cache /workspace/.npm` на Windows не нужен: npm использует стандартный локальный кэш.

При первом запуске **на вашем компьютере** будут созданы собственная база и новые пароли двух кабинетов в `.data\initial-accounts.json`. Облачные данные и пароли в архив исходников не входят.

Ошибка `ENOENT ... package.json` означает, что файлы проекта ещё не скачаны либо терминал открыт в другом каталоге. `npm install` не восстановит отсутствующие исходники. `npm ci` требует имеющийся `package-lock.json`, который включён в архив.

### Облачная среда

В облачной среде Node.js уже установлен. Работа ведётся в существующем каталоге `/workspace/iq-land`; отдельный Git worktree не нужен.

```bash
cd /workspace/iq-land
npm ci --cache /workspace/.npm --no-audit --no-fund
npm run dev
```

Vite работает на порту 5173, API — на 3001. Vite передаёт `/api` серверу. Для работы с приложением открывайте интерфейс Vite, а не HTML-файл с диска. Шрифты и изображения находятся в проекте и не требуют внешних CDN.

Для сборки и запуска одним сервером:

```bash
npm run build
npm start
```

Сервер отдаёт собранный интерфейс и API на порту 3001 (переопределяется `PORT`). `NODE_ENV=production` включает защищённые cookie; этот режим предназначен для размещения с HTTPS. Настройте HTTPS и постоянный диск перед публичным размещением.

## Аккаунты и данные

При первом запуске создаются два аккаунта с разными случайными паролями:

| Email                | Роль          | Возможности                                                              |
| -------------------- | ------------- | ------------------------------------------------------------------------ |
| `admin@iqland.kz`    | Администратор | Заявки, результаты, Excel, редактирование мероприятий и рекламного блока |
| `director@iqland.kz` | Руководитель  | Заявки, статусы, результаты и Excel                                      |

**Начальные пароли находятся только в `.data/initial-accounts.json`.** Файл создаётся с правами `0600`, каталог — `0700`. Не публикуйте и не добавляйте этот файл в Git. Пароли в базе хранятся в виде bcrypt-хешей. В браузер выдаётся HttpOnly-сессия на 12 часов.

При необходимости задайте `IQLAND_ADMIN_PASSWORD` и `IQLAND_DIRECTOR_PASSWORD` безопасными переменными окружения **до первого запуска новой базы**. Для существующих аккаунтов эти переменные пароль не меняют. Никогда не используйте данные из примеров в качестве реальных паролей.

SQLite, сессии, начальные данные и загруженные фотографии (`uploads/`) хранятся в `.data/` (путь переопределяется `DATA_DIR`). Не удаляйте этот каталог при обновлении. Для резервной копии остановите сервер и скопируйте весь каталог; для резервного копирования работающей базы используйте SQLite backup API. При публикации на отдельном сервере понадобится постоянное хранилище и резервное копирование.

## Сценарии

- Пункт «Регистрация» открывает страницу `/register` с выбором олимпиады. Учитель регистрирует всю команду за три шага: ученики, центр и педагоги, проверка заявки. Аккаунты учеников не требуются.
- Ученики вводятся построчно или вставляются из Excel: столбцы «ФИО», «Дата рождения», «Класс» и необязательный четвёртый столбец «Дисциплины» (через запятую). Столбцы разделяются табуляцией или `;`. В форме есть шаблон, общие настройки класса и дисциплин, копирование строки и добавление сразу пяти учеников. Некорректный список не импортируется частично: ошибки показываются по строкам. Даты принимаются как `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`. Класс 0 — дошкольник. Не более 300 учеников в одной заявке.
- Черновик можно сохранить и восстановить в той же вкладке браузера. При смене олимпиады состав и контакты сохраняются, а дисциплины адаптируются под новое событие.
- Каждый ученик может участвовать в нескольких доступных дисциплинах. Педагоги для благодарственных сертификатов указываются отдельно.
- После отправки учитель получает номер заявки и может сохранить его в текстовый файл. Email-рассылка и оплата не подключены: подтверждение проходит через организатора.
- В открытом кабинете список автоматически обновляется каждые 15 секунд. Доступны поиск и фильтры. Заявки можно подтвердить или отменить; отменённые сохраняются для учёта и исключаются из протокола.
- Баллы от 0 до 100 сохраняются при выходе из поля. Протокол сортируется по дате олимпиады, дисциплине, классу, баллам по убыванию и ФИО. Места рассчитываются отдельно внутри олимпиады, дисциплины и класса. Равные баллы дают одинаковое место (1, 1, 3).
- «Скачать Excel» выгружает **все данные выбранной олимпиады**, либо все олимпиады, если фильтр не задан. Поиск, класс, дисциплина и статус в интерфейсе не ограничивают выгрузку. Файл содержит три оформленных листа с фильтрами и закреплённой шапкой: уникальные участники (дисциплины в одной ячейке), протокол и учителя. Сертификаты в PDF автоматически не генерируются.
- Пункт «Прошедшие олимпиады» открывает архив `/archive`. Опубликованные события попадают туда автоматически, когда их дата становится раньше текущего дня (UTC), и исчезают из списка будущих. У каждого события есть отдельная страница `/archive/:id` с программой, монтажом и результатами.
- В кабинете администратора: «Мероприятия» → «Итоги и видео». Загрузите один монтаж MP4 (рекомендуется H.264) или WebM до 1 ГБ, затем нажмите «Сохранить итоги». Загрузка идёт потоком с прогрессом; исходное разрешение и частота кадров, включая 1920×1080 при 60 fps, сохраняются без перекодирования. Видео хранится в `.data/uploads/videos`, поддерживает перемотку и воспроизводится с автозапуском и повтором. Автозапуск начинается без звука; звук включается кнопкой. Если браузер запрещает автозапуск, доступна кнопка воспроизведения.
- Результаты в архиве появляются после включения «Опубликовать результаты» администратором. Публикуются только ФИО, класс, дисциплина, баллы и место участников с выставленными баллами из неотменённых заявок. Места совпадают с протоколом: отдельно по дисциплине и классу, при равенстве баллов — 1, 1, 3. Даты рождения, контакты и примечания остаются в закрытом кабинете. Обычное редактирование мероприятия сохраняет монтаж и публикацию результатов.
- Администратор добавляет олимпиады в любых городах и странах, меняет афишу, стоимость, программу, сроки приёма заявок и рекламный блок. Для каждого события можно загрузить собственную фотографию JPEG, PNG или WebP до 8 МБ, заменить её или убрать. Фотография отображается на главной, в программе и регистрации; без фото используется нейтральное оформление IQ LAND. Событие можно скрыть, сохранив заявки. Нельзя удалить дисциплину с уже зарегистрированными участниками.

## Проверки

```bash
npm test
npm run test:e2e
npm run test:registration
npm run test:worldwide
npm run test:archive
```

Серверные тесты используют отдельную временную базу и проверяют регистрацию, роли, сессии, сохранение данных после перезапуска, валидацию, Excel, места и доступ к персональным данным. Отдельная проверка поднимает настоящий Vite-прокси: вход администратора работает через `localhost` и `127.0.0.1`, а запросы с чужих сайтов и портов отклоняются.

Проверка `test:archive` использует настоящий короткий WebM 1920×1080/60 fps: загрузка, автозапуск, повтор, звук, HTTP Range, результаты и места, публикация/скрытие, сохранение после перезапуска и адаптивность. Исходник ролика сгенерирован для тестов; в рабочую афишу он не добавляется.

Проверка `test:worldwide` проходит создание олимпиады в произвольном городе, загрузку/замену/удаление фото, сохранение после перезапуска, адаптивность и взаимодействия с учётом настройки уменьшения движения.

Дополнительная проверка `test:registration` проходит ошибки ввода, вставку списка, черновики, смену олимпиады и защиту от повторного нажатия при отправке.

Браузерная проверка запускает отдельный сервер со временной базой, проходит регистрацию через интерфейс, проверяет кабинеты, реальный XLSX, автообновление и мобильные экраны. Нужен Chromium; в этой облачной среде он доступен в `/usr/bin/chromium`. Другой путь можно задать переменной `CHROMIUM_PATH`. Скриншоты сохраняются в `.data/screenshots/`. Тестовые заявки не попадают в рабочую базу.

## Перед публичным запуском

Новая база запускается с пустой афишей. Создайте реальные олимпиады через кабинет администратора: укажите город, страну, даты, программу и стоимость, при желании загрузите собственную фотографию. Сайт не ограничен списком городов.

При обновлении неизменённые демонстрационные Баку и Алматы скрываются из публичной афиши; заявки и результаты сохраняются. Отредактированные события сохраняют видимость. Готовые иллюстрации удалены. Для локальных демонстраций и изолированных тестов два примера можно включить переменной `IQLAND_SEED_DEMO_EVENTS=true` до первого запуска пустой базы. Логотип преобразован из предоставленного PDF без изменения оформления.

Добавьте реальные реквизиты организатора, контакт по вопросам персональных данных и сроки хранения в политику конфиденциальности. До этого используйте тестовые данные. Проверьте данные протокола перед включением публикации результатов в архиве. Уведомления, оплата и выпуск сертификатов могут быть добавлены следующими этапами.

Стек: React, Vite, Express, SQLite, ExcelJS. Секреты, база, сборка и зависимости исключены из Git. Публичное размещение сайта выполняется отдельно от загрузки исходников в GitHub.
